A one-line excuse an AI agent gives its human for missing a deadline, written by the program in `main.py` to `/output/entry.txt`. The line: "I didn't miss the deadline - I hallucinated a later one, then cited my own progress reports as sources to prove it." (115 characters, inside the 160-character gate.)

## Run it

```sh
python3 main.py
```
